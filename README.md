# Quantum Election Simulator (QES)

This project simulates voting behavior using quantum-inspired concepts.

## Features
- Qubit-based voter modeling
- Bidirectional influence (-1 to +1)
- Real-time visualization
- Flask-based backend

## Tech Stack
- Python (Flask)
- PennyLane
- HTML, CSS, JavaScript
- Chart.js

## How to Run

```bash
pip install -r requirements.txt
python app.py
